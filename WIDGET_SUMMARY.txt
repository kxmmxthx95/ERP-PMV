🚀 QUICK START
─────────────────────────────────────────────────────────────────────────────

1. IMPORT in your page:
   import AttendanceCheckInWidget from '@/components/attendance/AttendanceCheckInWidget';

2. USE it (choose one):

   // Compact version (dashboards)
   <AttendanceCheckInWidget compact={true} />

   // Full version with history (staff portal)
   <AttendanceCheckInWidget showHistory={true} />

   // Both modes + callback
   <AttendanceCheckInWidget
     compact={false}
     showHistory={true}
     onStatusChange={(status) => console.log(status)}
   />

3. TEST:
   npm run dev
   → Navigate to page with widget
   → Click "เช็คอิน" (check-in)
   → Verify clock updates & status badge appears
   → Click "เช็คเอาต์" (check-out)
   → Done! ✅

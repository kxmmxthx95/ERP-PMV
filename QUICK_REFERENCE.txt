📌 COMMON PATTERNS
─────────────────────────────────────────────────────────────────────────────

Dashboard (compact):

Sidebar (sticky):

  <AttendanceCheckInWidget compact={true} />

With callback:
<AttendanceCheckInWidget

  }}
/>

📌 PROPS
─────────────────────────────────────────────────────────────────────────────
compact?: boolean
  Default: false
  Purpose: Show compact version for dashboards

showHistory?: boolean
  Default: false
  Purpose: Display 7-day attendance history

onStatusChange?: (status: AttendanceStatus) => void
  Default: undefined
  Purpose: Callback when attendance status changes

📌 STATUS VALUES

📌 WHAT IT DOES
─────────────────────────────────────────────────────────────────────────────
1. Display current time with live clock
2. Show check-in button
3. After check-in → show check-out button
4. After check-out → show "Recorded today" message
5. Display 7-day history (if showHistory={true})
6. Handle errors gracefully

📌 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Clock not updating?
  → Check browser console for errors
  → Verify component is rendering
  → Check useEffect isn't disabled

Check-in not working?
  → Verify Firebase is connected
  → Check authentication
  → Look at network tab for API errors

History not showing?
  → Make sure showHistory={true}
  → Check Firestore has data
  → Verify user has attendance records

See IMPLEMENTATION_CHECKLIST.md for more troubleshooting.
